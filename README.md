# abe - Android backup extractor

## Usage

**Unpack**

```sh
abe unpack <backup.ab> <password>
```

**Pack**:

```sh
abe pack <backup.tar> <password>
```

> Password is optional, can leave empty.

## Install

```
go install github.com/garudaproject/abe@latest
```

**download**

- <https://github.com/garudaproject/abe/releases>
